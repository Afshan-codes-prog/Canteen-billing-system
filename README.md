# CanteenX – College Canteen Billing System

**CanteenX** is a simple, menu‑driven billing application built in **C** for college canteens.  
It allows users to browse the menu, select food items, enter quantities, and generate a bill with item‑wise details and the total cost.

---

## ✨ Features
- Display canteen menu with item prices  
- Select food items by number  
- Enter quantity for each item ordered  
- Calculate cost of individual items  
- Generate a final bill with item‑wise breakdown and total amount  

---

## 🛠️ Technologies Used
- C Programming Language  
- Functions  
- Arrays  
- Loops and Conditional Statements
